~/config

Config reference

Every setting in hyprtile.conf, what it does, what it accepts and its default. Try the look settings on the mockup first, then copy the lines.

how it works

How the file works

  • Open it from the menu, text and json editor, or hold an empty spot and use settings. Save and everything reloads live.
  • The syntax follows Hyprland: section { key = value }, sections can nest, # starts a comment.
  • A bad value or an unknown key is skipped and listed as a note. The rest of the file still loads, so one typo never breaks home.
  • Numbers outside the allowed range are pulled back to the nearest end, not rejected.
  • If a file crashed home three times, Hyprtile runs the fresh look from memory until you change the file. A file over 1 MB is set aside as hyprtile.conf.toobig.
  • Reset to defaults is the last row of help. It keeps your old file as hyprtile.conf.bak.
  • Anything not in the file keeps its default. A shared file never holds passwords, health data or what is running.

section
workspace and split lines


These are plain lines, not inside a section. A page holds the windows listed after its number, in tiling order. Up to nine pages.


# tiled page, windows in tiling order
workspace = 2, name:media, btop, cliamp
# free page: a 4 column by 8 row grid, each box is width x height + column + row
workspace = 5, grid 4x8, clock 4x2+0+0, weather 4x3+0+2
# a different layout when the phone is turned, after a slash
workspace = 6, grid 4x8/8x4, clock 4x2+0+0/4x2+0+0
# the sizes you dragged: one ratio per split, h or v for the direction, - to leave one alone
split = 2, 0.6, 0.45v




workspace = N, ...
N is the page, 1 to 9. Then optional name:text (shown on the bar and in menus), optional grid CxR, then the windows.


window kind
One of the kinds listed in the guide, like clock, terminal, weather, btop, cliamp, cava, notifications, apps, shelf, calendar, pomodoro, notes and many more. Pro and insider kinds are marked in the app.


box
width x height + column + row from the top left of the grid, only on pages with grid.


black
With pro, workspace = 4, black is a full black page with no scene, and no bar while it is empty.


split = N, ...
Each value is 0.05 to 0.95. Add h or v to fix the direction. Dragging the gap between two windows writes this for you.
